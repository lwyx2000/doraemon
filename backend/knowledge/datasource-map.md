# 数据源地图总览

## 架构

```
doraemon (backend :9080)
  └─ 纯接口取数 → aksharewebapi (:8000, 53 内网 10.100.213.248:8000)
                     └─ AkShare / 直连接口（腾讯、新浪、东财、中证、集思录…）
```

- doraemon 不直连上游，一律经 aksharewebapi 网关（指数 PB/PE、板块、资金流等）。
- 网关侧 MySQL `t_index_valuation` 自持指数估值历史，每日 18:35 腾讯增量；Redis 缓存 2h，写库后 invalidate_cache。

## 三态区分（限流/不覆盖/陈旧）——判停铁律

| 状态 | 含义 | 处置 |
|---|---|---|
| 限流失败 | 异常抛出、可重试 | 退避重试 |
| 源不覆盖 | 正常返回空、永久放弃 | 标记 no_data |
| 有行没落库 | 数据陈旧、可重试 | 重新抓取 |

- 停止条件：`pending == 0`。
- **新鲜度只看数据时间戳**（对照交易日历），不看来没来请求。
- **请求路径绝不刷上游**（force=0 走本地）；改取数逻辑后必须 grep 全部调用点确认无偷偷刷上游。

## 降级原则

- 取数失败 → 如实说明数据缺失 / 分区骨架屏 + 重试按钮，**绝不伪造数据**。
- 上游 5xx/限流 → fail-fast 降级并标注数据来源（is_mock / gatewayEmpty）。
