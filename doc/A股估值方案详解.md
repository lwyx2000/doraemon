# A股估值方法详解：股债利差 + 拥挤度体系

> 本文基于「韭菜投资学」的估值体系整理，核心思路：**用"股债利差"判断 A 股整体贵不贵，用"拥挤度"判断行业之间谁更便宜。**

---

## 一、这套方案要解决什么问题

股票收益有两个基本来源：**公司盈利** 和 **估值变化**。

- **盈利的钱**：长期持有指数即可获得。例：沪深300 从 2005 年持有至 2018 年底，含分红年化净收益 9.76%，而当时市场情绪和估值都处于低位，这个收益主要来自公司盈利。
- **估值的钱**：市场狂热时股价涨到离谱，悲观时好股票也变得很便宜。A股散户占比高，这一现象更明显。**在低估时买入、高估时卖出，就能赚取超额收益。**

整套方案要输出三个可操作的量：

| 要回答的问题 | 对应指标 | 作用 |
|---|---|---|
| A股整体现在贵不贵？ | 估值分位（基于股债利差） | 定总仓位、定股债比例 |
| 各行业/指数之间谁相对便宜？ | 拥挤度 | 选品种、做行业轮动 |
| 具体买什么基金？ | 场内/场外基金代码 | 落地执行 |

---

## 二、为什么不用常见的两种估值法

### 2.1 横向比较法（A股 vs 美股/港股）

> 例："上证50市盈率9.9倍，明显低于标普500的24倍"

隐含两条假设：
1. 各个市场环境相似；
2. 资本可以自由跨市场流动。

**现实完全不满足**：投资者结构、制度完善度、监管尺度、汇率政策、税务成本差异巨大，尤其我国存在资本管制。因此 A股作为相对独立市场，直接横向比较意义不大。

### 2.2 历史比较法（PE/PB 历史百分位）

> 例：当前市盈率10倍，过去10年中20%的时间低于10倍 → 百分位20%

**四个硬伤：**

1. **历史起点不同，百分位不可比。** 沪深300 用10年算出20%、中证500 用5年算出30%，无法判断谁更低。
2. **财报滞后。** PE 用 TTM（最近四季度财报），忽略业绩快报。2019年2月创业板商誉爆雷，业绩快报已预告巨亏，但年报未披露，估值没反应。
3. **最致命：忽略环境变化，尤其利率。** 股票 PE 10倍 = 年赚10%；若国债给15%，没人买股票；若国债仅1%，股票就有吸引力。**股价和盈利能力一点没变，光是利率变了，"贵还是便宜"的结论就完全相反。**
4. **以 PE 为核心容易失真。** 净利润受周期、意外事件冲击大。有色这类强周期行业，不赚钱时不等于一文不值，用 PE 会误判。

## 三、A股整体估值：股债利差三步法

### 3.1 理论基础：股票定价的三因素

| 因素 | 性质 | 说明 |
|---|---|---|
| 无风险利率 | 外部条件 | 利率越低 → 贴现率低 → 股价越高 |
| 公司业绩 | 内部条件 | 盈利越好 → 股价越高 |
| 风险溢价 | 市场情绪 | 反映投资者承担风险的意愿 |

前两者是**基本面**（用于确定"真实价值"），风险溢价是**情绪**（用于找买卖时机）。

### 3.2 第一步：考虑无风险利率

1. 取 PE 的倒数 `1/PE` = 股票的投资收益率
2. 减去 **10年期国债到期收益率** = 股债收益率差
   - 差值越大 → 股票相对越便宜
   - 差值越小 → 股票明显高估
3. 通胀调整：**+ 30% × 当月同比 CPI**
   - 逻辑：通胀时债券实际收益被侵蚀更厉害，股票天然抗通胀，通胀加速时资金更偏好股票

> **利差越大 → 股票相对债券越有吸引力 → 越便宜。**

### 3.3 第二步：考虑公司业绩（为什么改用 PB）

**核心实证规律：市场整体的 ROE 长期在固定区间内波动、向均值回归。**

- **美国 1964–2014**（50年，穿越石油危机、1981-82衰退、互联网泡沫、次贷危机）：市场平均 ROE 基本在 **8%–16%**，仅2001和2009两次危机短暂恶化后迅速恢复。
- **中国 1998–2018**（21年）：上市公司总体 ROE 在 **5.56%–18.91%** 之间。

**为什么会均值回归？** 市场在自我换血：差企业被淘汰/剔除出指数，新兴企业纳入并贡献利润，资本从差企业抽离注入好企业。资本永远要求足够回报，于是 ROE 被拉回均值。这与指数编制原理天然契合。

> 这里讨论的是**市场整体 ROE**，不是单家公司 ROE。

**因此结论反直觉：对市场整体，应该在 ROE 低的时候买。**

- ROE 低 → PE 通常也低 → 等待经济复苏 → 赚"盈利+估值"双份钱
- ROE 高 → 市场火热、PE 已高 → 应该卖出

用 PE × ROE 双维度分四象限：

| | ROE 高 | ROE 低 |
|---|---|---|
| **PE 高** | 泡沫（应卖） | A：估值虚高 或 提前反映盈利好转 |
| **PE 低** | B：估值低 或 提前反映萧条 | 低估机会（应买） |

因为 `PB = PE × ROE`，所以 **PE 与 ROE 双低 ⇔ PB 低；双高 ⇔ PB 高**。结论变为：

> **应该在市场低 PB 时买入，高 PB 时卖出。整套方法的核心指标统一换成 PB。**

**为什么 PB 更有效？** 因为 ROE 会均值回归，资产产生利润的能力长期稳定，只要在 PB 更低（资产更便宜）时买入，给时间等待盈利复苏即可。

### 3.4 第三步：合并，算分位

完整公式链：

```
均值PE = PB ÷ 近年市场ROE均值
投资收益率 = 1 / 均值PE = ROE均值 ÷ PB
股债利差 = 收益率 − 10年期国债收益率 + 0.3 × CPI同比
估值分位 = 该利差在2005年至今历史中的百分位
```

**数据选择：**
- 整体估值：万得全A指数（覆盖两市全部A股，自由流通股本加权），从 2005 年起
- PE/PB 计算纳入业绩快报，使估值更及时

⚠️ **分位方向（最易读反）：**

估值分位 = 比历史上百分之多少的时候**更贵**，等价于 `1 − 利差的升序百分位`。

- 分位越小 = 当前利差越大 = 越便宜
- 例：分位 34.20% 表示"比2005年以来约70%的时间都更便宜"

**读数规则：**

| 估值分位 | 含义 | 动作 |
|---|---|---|
| < 30% | 便宜，价值机会区 | 买入并长期持有 |
| 30%–70% | 正常 | 持有，获取市场平均收益 |
| > 70% | 过热 | 降仓位、防回撤 |

## 四、行业/指数：拥挤度

**拥挤度衡量的是相对估值。**

### 4.1 算法三步

1. `某指数/行业PB ÷ 万得全A的PB = 估值倍数`
   - 例：全A的PB=1.5，沪深300的PB=1.2 → 倍数 = 0.8
2. 从 **2010年6月**起（创业板起点，保证所有样本区间一致、彼此可比），逐日计算
3. 今天的倍数在历史倍数序列中的分位 = **拥挤度**

**关键：分母用 A股整体 PB，消掉了大盘涨跌的影响**，剩下纯粹的行业间比价关系。这比"行业自身PE百分位"更灵敏、更适合轮动。

### 4.2 示例（文章发布时点）

| 指数/行业 | 拥挤度 | PE | PB |
|---|---|---|---|
| 饮料 | 81.1% | 30.95 | 6.26（最"热"） |
| 证券 | 73.9% | 49.51 | 2.08 |
| 沪深300 | 54.5% | 13.31 | 1.58 |
| 创业板 | 58.8% | 56.33 | 4.87 |
| 医药 | 27.4% | 36.83 | 3.83 |
| 中证红利 | 31.6% | 8.62 | 1.13 |
| 银行 | 31.4% | 7.18 | 0.92 |
| 中小板 | 34.7% | 27.75 | 3.67 |
| 中证500 | 10.3% | 26.51 | 2.18 |
| 传媒 | 3.2% | 105.35 | 2.25（相对最便宜） |

### 4.3 使用铁律（最易用错）

> **拥挤度低 ≠ 绝对便宜。**

假设 A股涨到天上，中小盘涨得更多，沪深300 拥挤度会显示很低——这只说明它"相对其他指数更便宜"，绝对估值依然很贵。

**正确顺序：**
- **总体估值低** → 优先买拥挤度低的品种
- **总体估值高** → 优先卖拥挤度高的品种

**配置建议：** 宽基打底 + 不拥挤行业做增强，不要单押行业（行业发展和政策不确定性会放大风险暴露）。

## 五、落地操作：三条策略

### 5.1 股债平衡

| 状态 | 股票 : 债券 |
|---|---|
| 总体低估 | 75 : 25 |
| 总体高估 | 25 : 75 |
| 从极端回归并越过50%分位 | 50 : 50 |
| 一年内未触发调整 | 每年固定再平衡一次 |

### 5.2 定投强度

| 估值分位 | 动作 |
|---|---|
| < 30% | 加大定投金额 |
| 30%–50% | 按标准金额定投 |
| 50%–70% | 暂停定投 |
| > 70% | 逐步卖出 |

### 5.3 执行提醒（作者强调）

**不要一分位触线就立刻调仓。** 估值是大致范围，趋势有惯性——低估后还可能更低估，狂热后还可能更狂热。

建议：**结合趋势指标**，或 **分步渐进买卖**。

## 六、方案的优点与局限

### ✅ 优点

- 用无风险利率做锚，补上历史百分位法"忽略环境变化"的致命伤
- 统一历史起点（整体2005年、行业2010年6月），跨指数/行业可比
- 改用 PB + ROE 均值回归，规避周期股 PE 失真
- 纳入业绩快报，数据更及时
- 拥挤度剔除大盘影响，适合行业轮动

### ⚠️ 局限（需留个心眼）

- **分位是"相对自身历史"的位置，不是收益预测。** 低分位不代表马上涨，可能长期更低估
- **多个参数是经验设定，非理论推导：** 通胀调整用 `30% × CPI`、ROE 取"近年均值"、起点选 2005/2010.6 —— 选择会影响分位绝对值
- **样本内偏差：** 历史区间越短、结构变化越大（金融股权重变化、盈利结构变迁），PB 中枢会漂移
- **隐含假设：** ROE 长期均值回归、10年期国债可代表无风险利率 —— 若经济结构发生**趋势性**变化（非周期波动），回归逻辑会失效
- **风险溢价（情绪）未被量化**，是整套体系最"软"的一环
- **拥挤度只含相对信息：** 市场整体很贵时，"最不拥挤"的行业也可能不便宜

## 七、附录：只有 PE 数据、没有 PB，怎么办？

**能用，但不能直接用 PE_ttm 替代**，否则会踩进**方向性陷阱**——这正是作者弃用 PE 改用 PB 的原因。

### 7.1 理论终点其实就是 PE 的倒数

```
均值PE = PB ÷ ROE均值
收益率 = 1/均值PE = ROE均值 ÷ PB   ← 算到这步指标已是 PE 的倒数
股债利差 = 收益率 − 国债收益率 + 0.3 × CPI
估值分位 = 该利差在2005年以来的百分位
```

PB 只是求 PE 的**中间跳板**。绕这一下的原因是直接用当期 PE 有致命问题。

### 7.2 PE_ttm 的周期陷阱（方向是反的）

PE = 市值 ÷ 净利润，**净利润波动大、净资产相对稳定**：

| 市场位置 | 净利润 E | PE_ttm | 1/PE | 利差 | 分位显示 | 真实情况 |
|---|---|---|---|---|---|---|
| 周期底部 | 被压缩/亏损 | 虚高（或为负） | 变小 | 变小 | **显得贵** | 其实便宜 |
| 周期顶部 | 盈利膨胀 | 虚低 | 变大 | 变大 | **显得便宜** | 其实危险 |

**用 PE_ttm 算利差，会让你在底部觉得贵、顶部觉得便宜——完全反向。**

### 7.3 可行的替代方案

**方案 1（推荐）：调和平均 PE —— 只需历史 PE 序列**

与原版同构：用"历史 PE 序列自己平滑自己"实现周期中性化，不需 PB、不需 E 序列。

```
① 收益率_t = 1 / PE_t        （过去 N 年每个交易日）
② 平滑收益率 = mean(收益率_t)  （1/PE 的算术平均 = PE 的调和平均）
③ 股债利差 = 平滑收益率 − 国债收益率 + 0.3 × CPI同比
④ 滚动 N 年窗口回溯，得历史利差序列
⑤ 今日利差在该序列中的百分位 = 估值分位
```

实操提醒：
- **N 取 5–7 年**（A股全A数据2005年才起，取10年吃掉大半样本，且盈利结构变化快）
- **PE 为负要单独处理**（指数整体亏损时 1/PE 无意义甚至符号反转，需剔除/截断）——这是 PE 版相对 PB 版**无法完全克服**的硬伤
- 统一用 PE_ttm，优先选已纳入业绩快报的数据源
- PE 序列通常比 PB 序列更好找，落地可行性高

**方案 2：有 ROE 就反推 PB**

```
PB = PE × ROE
```

反推后原版公式全部可用。ROE 可从指数成分股财报汇总获得，比 PB 序列易找。

**方案 3：股息率交叉验证**

只有单点 PE 时，股息率是有用的旁证——**分红远比净利润稳定**，天然带周期中性属性。
- 股息率高 + PE 也便宜 → 结论可信
- 股息率低 + PE 显便宜 → 大概率盈利虚高（周期顶部），警惕

注意 A股分红率趋势性提升，历史可比性有瑕疵，只做旁证。

**方案 4：只有单点 PE_ttm 的降级用法**

直接算 `1/PE_ttm − 国债收益率 + 0.3×CPI` 得利差，**别直接看历史分位**，而是与"PE 自身历史分位"交叉对照：
- 两者方向一致 → 相对可靠
- 严重背离 → 大概率盈利周期作怪，以 PB/ROE 逻辑为准，谨慎下注

### 7.4 拥挤度用 PE 替代要更小心

拥挤度 = `行业PB ÷ 全A PB` 的分位 → 换成 PE 即 `行业PE ÷ 全A PE` 的分位。**分母同为全A，能消掉大盘涨跌，这部分逻辑对**，但失真更严重：

1. 各行业盈利周期不同步 → 比值被周期错位主导
2. 各行业 PE 波动幅度差异极大（银行5-10倍 vs 传媒30-150倍）→ 比值噪声大
3. PB 分子分母都是净资产，天然稳定，比值才"干净"

**建议：**
- 优先找 PB（银行、地产、钢铁等重资产/周期行业，PB 本是行业惯例）
- 只有 PE 时，**只用于盈利相对稳定的行业**（医药、消费、沪深300），避开强周期
- "行业PE/全A PE 分位" 与 "行业 PE 自身历史分位" 互相验证，一致才采信

### 7.5 反直觉补充：PB 并非处处更优

- **重资产 / 强周期**（银行、地产、钢铁、券商）→ PB 更可靠。券商尤典型：牛市盈利暴涨，PE 显得异常"便宜"，是最经典的 PE 陷阱
- **轻资产 / 高成长**（传媒、互联网、服务、部分科技）→ 净资产小，PB 天然虚高，会系统性高估其"贵"的程度，这类行业 PE（或 PS、PEG）反而更有参考价值

**"只有 PE"在轻资产行业未必是劣势，真正危险的是拿 PE 判断全市场整体和强周期行业。**

### 7.6 落地检查清单

| 手里的数据 | 推荐做法 | 可信度 |
|---|---|---|
| PB + ROE | 原版公式 | ★★★★★ |
| 历史 PE 序列（5-7年） | 调和平均 PE 版 | ★★★★ |
| PE_ttm + ROE | 反推 PB 后用原版 | ★★★★ |
| PE_ttm + 历史 PE 分位 | 利差与 PE 分位交叉验证 | ★★★ |
| 只有单点 PE_ttm | 仅作方向参考，配股息率旁证 | ★★ |
| 强周期行业 + 只有 PE | **别用**，结论大概率反向 | ✕ |
