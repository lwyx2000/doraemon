这是一份经过全面整合、细化并补充了**策略管理**与**AI配置/决策模块**的**A股基金与可转债行情分析系统需求文档（PRD）**。

本方案旨在提供一个可以直接对接您的 HTTP 数据接口、具备量化筛选能力、并能引入大语言模型（LLM）进行每日智能分析的落地蓝图。

# A股基金与可转债智能分析系统产品需求文档 (PRD)

## 一、 系统概述与架构设计

### 1.1 系统定位
本系统专为低风险套利、可转债轮动及大类资产配置设计，**不直接分析单只股票**（仅将正股数据作为可转债的定价支撑）。

### 1.2 系统架构与数据流向
```
[HTTP 行情接口] ──> [数据同步/计算引擎 (计算ERP、双低、折溢价)]
                           │
                           ▼
                  [系统本地数据库 (PostgreSQL / Redis)]
                           │
    ┌──────────────────────┴──────────────────────┐
    ▼                                             ▼
[前端 UI 页面 (展示/筛选/策略配置)]        [AI 决策引擎 (LLM API 中转)]
    │                                             │
    └──────────────────────┬──────────────────────┘
                           ▼
                  [每日智能决策报告 / 预警推送]
```

## 二、 核心页面详细功能设计

系统共规划 7 个核心页面。

### 页面一：大类资产配置与宏观深度看板 (Macro Allocation Dashboard)
*   **核心功能**：研判“股债相对性价比”及资金面紧张程度。
*   **关键指标**：
    *   **ERP（股权风险溢价）**：$\text{ERP} = \frac{1}{\text{沪深300 PE(TTM)}} - \text{十年期国债收益率}$。提供当前数值、历史分位数（3年/5年/10年）。
    *   **资金利率**：DR007、GC001 实时数值及偏离度。
    *   **核心指数估值百分位热力图**：上证50、沪深300、中证500、中证1000的 PE/PB 历史百分位（颜色深浅表征估值高低）。

### 页面二：场内基金估值与套利扫描页 (Fund Arbitrage Screen)
*   **核心功能**：实时扫描 LOF、QDII、封闭基金的折溢价状态，捕捉套利机会。
*   **关键指标**：场内价格、实时估算净值（IOPV）、实时折溢价率（%）、折溢价率历史分位数、预估净套利收益率（%）（自动扣除申购/赎回摩擦成本）。
*   **QDII 修正**：引入标的海外指数期货的盘中涨跌幅，对前一日官方净值进行实时修正。

### 页面三：可转债多因子扫描页 (Convertible Bond Scanner)
*   **核心功能**：支持多因子筛选，并实时监控可转债各种条款触发进度。
*   **关键指标**：
    *   **基本指标**：转债价格、转股溢价率、纯债溢价率、到期收益率 YTM。
    *   **衍生因子**：双低值（价格 + 溢价率 × 100）、隐含波动率 IV、正股历史波动率 HV。
    *   **条款计数器**：强赎触发进度（如 11/15 天）、回售触发进度（如 20/30 天）、下修触发进度。
    *   **正股风控**：正股财务安全度指标（Altman Z-Score、大股东质押率、是否含 *ST 风险）。

### 页面四：公募 REITs 深度价值分析专页 (Public REITs Hub)
*   **核心功能**：针对公募 REITs 底层资产价值评估与分红率跟踪。
*   **关键指标**：底层项目名称、当前市价、年度预估分配金额（元）、分红率（%）、内部收益率 IRR（%）（特许经营权类专用）、底层资产出租率。

### 页面五：策略管理中心 (Strategy Management Center) —— 新增

**页面定位**：用户在此页面以“无代码/低代码”形式组装、定义自己的投资策略，作为 AI 分析和系统自动筛选的规则库。

```
+-------------------------------------------------------------------------+
| [新建策略]  [策略模板导入]                                              |
+-------------------------------------------------------------------------+
| 策略名称: [双低可转债轮动策略  ] 目标资产: (o) 可转债 ( ) LOF ( ) REITs   |
| 规则配置 (逻辑生成器):                                                   |
| [ 价格 ]  [ < ]  [ 115 ] 元  [AND]                                      |
| [ 转股溢价率 ] [ < ] [ 15 ] % [AND]                                     |
| [ 信用评级 ] [ 属于 ] [ AA, AA+, AAA ]                                  |
| [ + 添加条件 ]                                                          |
+-------------------------------------------------------------------------+
| 已存策略列表:                                                            |
| 1. 双低可转债轮动策略 (处于激活状态)                         [修改] [删除] |
| 2. QDII 溢价套利策略 (阈值: 净收益 > 1.5%)                  [修改] [删除] |
+-------------------------------------------------------------------------+
```

#### 5.1 核心功能组件
1.  **策略创建器（Strategy Builder）**：
    *   支持选择目标资产（可转债/LOF/封闭基金/REITs）。
    *   支持多条件“AND/OR”逻辑组合。
    *   **可选参数因子库**：
        *   *可转债*：双低值、价格、转股溢价率、YTM、信用评级、剩余年限、剩余规模、正股Z-Score。
        *   *基金类*：实时折溢价率、历史折溢价分位数、净套利收益率、日均成交额、跟踪误差。
2.  **策略激活开关**：用户可以勾选哪些策略参与“每日AI扫描”。
3.  **策略模板库**：预设行业常用策略（如“经典双低轮动”、“高分红REITs筛选”、“QDII溢价套利”），支持一键复制。

#### 6.1 AI 引擎配置组件
*   **LLM 接口参数**：支持自定义模型厂商（如 OpenAI GPT-4o、Claude 3.5 Sonnet、DeepSeek-V3 等）、API 密钥、API 自定义地址、Temperature（建议设为 0.2-0.3 降低幻觉）。
*   **定时任务（Cron）配置**：设置每日自动运行的时间（例如每个交易日 15:30 盘后数据完整后执行）。

#### 6.2 每日决策报告展示区
展示 AI 生成的 Markdown 格式报告，包含三个固定板块：
1.  **市场温度计**：基于今日 ERP、资金利率、宽基指数估值，输出中性客观的宏观配比建议。
2.  **策略机会扫描结果**：AI 对满足“策略管理中心”激活规则的标的数据进行二次过滤，用文字叙述推荐理由及潜在风险（如强赎风险、信用风险）。
3.  **异动与套利提醒**：展示折溢价异常的基金名单及套利可行性评估。

## 三、 AI 决策工作流与后台数据交互设计

为保证 AI 每日报告的客观性与准确性，系统不应直接让 AI 去“盲猜”市场，而是采用 **RAG（检索增强生成）** 思想，将结构化数据清洗后喂给 AI。

### 3.1 每日 AI 执行流

```
[定时任务触发 (15:30)]
       │
       ▼
[系统提取数据] ──> 包括: ① 宏观数据(ERP、利率)
                         ② 已激活策略筛选出的标的数据列表
                         ③ 全市场可转债/基金异动Top10
       │
       ▼
[构建结构化 Prompt] ──> 合并数据与系统提示词(System Prompt)
       │
       ▼
[调用 LLM API] ──> 限制模型输出格式为标准 Markdown
       │
       ▼
[保存并渲染报告] ──> 写入数据库，并在前端"页面六"展示，同步推送到配置的通信渠道
```

### 3.2 系统提示词 (System Prompt) 模版

```text
你是一个专业的 A 股低风险投资智能体助理。
请基于以下由系统筛选出的结构化数据，生成一份客观、严谨、无夸大成分的盘后分析报告。

【今日宏观数据】
- 股债性价比 ERP: {erp_value} (历史分位数: {erp_percentile}%)
- 核心资金利率 DR007: {dr007_value}%, GC001: {gc001_value}%

【触发"双低转债策略"的标的列表】
{cb_strategy_data}

【触发"LOF溢价套利策略"的标的列表】
{lof_strategy_data}

【撰写要求】
1. 评估当前资产配置方向（偏股还是偏债），保持中立态度。
2. 逐一分析策略推荐的标的，重点核实这些标的是否存在潜在风险（如转债是否临近强赎日、正股是否有财务恶化退市风险、LOF 是否存在流动性陷阱）。
3. 严禁出现“稳赚不赔”、“完美契合”等绝对化词汇。所有分析应基于数据概率。
```

## 四、 核心非功能性需求与边界情况处理

### 4.1 IOPV 延迟与误差处理
场内 LOF 基金的 IOPV 估算净值存在 15 秒更新延迟。在计算套利收益率时，系统后台需根据持仓成分股盘中 Tick 级别走势自主模拟高频估算，并与官方 IOPV 进行比对校准。

### 4.2 停牌及特殊状态过滤
当可转债的正股停牌或基金暂停申购时，系统的套利逻辑需自动标记“暂停交易”，防止 AI 引擎因错误地提取历史价格而产生不可执行的套利建议。

### 4.3 接口速率与流式输出 (Stream)
AI 决策报告生成过程通常需要 10s - 30s。前端“页面六”展示时需支持 Stream 流式字符输出（打字机效果），避免页面卡死，并提供历史报告归档查询功能。
